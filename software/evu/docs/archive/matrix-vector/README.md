# Retired Matrix-Vector Coupling

These documents describe the former Launch, direct quantization, matrix
dequantization and fused FlashAttention implementation. That implementation was
retired on 2026-11-10. Commands, source paths, test names and performance results
in this directory refer to their original checkpoints, not the current ISA.
Relative links inside archived documents retain their original locations.

Historical source is available in the corresponding Git checkpoints, including
`checkpoint/evu-upstream-deps-20261105`. Current software and validation commands
are in [software/evu/README.md](../../../README.md) and
[EVU_PURE_VECTOR_PLAN.md](../../EVU_PURE_VECTOR_PLAN.md).

Existing `docs/checkpoints/` records are retained to identify the exact binaries,
dependencies, timing intervals and validation limits of old measurements.
