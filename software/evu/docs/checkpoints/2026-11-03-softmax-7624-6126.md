The helper first verifies the recorded dependency SHAs, then changes only
local submodule URL settings before initialization. It does not force

submodules; `make init` then initializes the nested dependencies explicitly
required by the repository, avoiding recursive traversal of unrelated nested
submodule pins. NEMU's SimPoint submodule is not required for its EVU reference
library build. A later `git submodule sync` restores
the tracked upstream URLs; rerun the helper before fetching these custom
dependency revisions again.
