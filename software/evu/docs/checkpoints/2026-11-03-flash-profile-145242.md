## Clone and initialize

Do not use `git clone --recurse-submodules` for XSAI. The tracked `.gitmodules`
intentionally retain upstream URLs, while several pinned historical dependency
commits are mirrored under `qihangGuo`. Clone the parent, initialize top-level
dependencies through the checkpoint helper, then initialize the nested set
explicitly listed by XSAI's Makefile:

```sh
git clone --branch checkpoint/evu-flash-profile-145242-20261103 \
  https://github.com/qihangGuo/XSAI.git XSAI_evu_checkpoint_20261103
cd XSAI_evu_checkpoint_20261103
bash software/evu/scripts/init_softmax_20261103_checkpoint.sh
make init

git clone --branch checkpoint/evu-flash-profile-145242-20261103 \
  https://github.com/qihangGuo/NEMU.git ../NEMU_evu_checkpoint_20261103
```

The helper verifies the pinned top-level commits, overrides CUTE, XSAICache and
utility URLs only in local `.git/config`, and initializes direct submodules.
`make init` loads the nested Rocket Chip, XSAICache and CUTE dependencies used
by this checkout. It does not rewrite the tracked `.gitmodules` file. The
matching NEMU reference has no required recursive submodule for this build.

This follow-up does not modify CUTE, XSAICache, utility, difftest or NEMU source.
It changes only the XSAI legality check, its test source, and checkpoint/clone
documentation. No local RTL generation, EMU run or guest-bin build is part of
this checkpoint delivery.
