In XSAI, synchronize and update difftest to the recorded revision:

```sh
git switch --detach checkpoint/evu-flash-warm-300289-20261028
git submodule sync -- difftest
git submodule update --init -- difftest
```

Use `feat/evu-optimization` for subsequent commits in each repository. Do not
move the checkpoint tag. Keep the existing CUTE, XSAICache and utility
checkouts at the revisions above when reproducing this local configuration.

The existing emu and NEMU binaries matching the supplied warm run can be
reused for software-only changes. RTL, difftest event-layout or ISA/model
changes require the corresponding server rebuilds. The warm guest command
from XSAI is:

```sh
make -C software/evu ARCH=riscv64-xs TOOLCHAIN=LLVM NAME=flash_attention_evu_correct_warm
./build/emu \
  --diff /nfs/home/guoqihang/workspace/NEMU_evu/build/riscv64-nemu-interpreter-so \
  -C 100000000 \
  -i software/evu/build/flash_attention_evu_correct_warm-riscv64-xs.bin \
  2>&1 | tee flash_attention_correct_warm.log
```

No emu, guest/native executable or Verilog is built or executed while saving
this checkpoint. The existing validation history and its limitations remain
in `FLASH_ATTENTION_OPTIMIZATION_ROADMAP.md`; older pending-server statements
there describe earlier milestones and are superseded by the warm result here.
