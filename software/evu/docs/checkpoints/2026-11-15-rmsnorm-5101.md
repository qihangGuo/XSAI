## Collector correctness fix

The earlier failing run stopped at `pc=0x80001e20`, instruction `0x697faa0b`,
the quantizer's first `amax / 6` divide. An E0 mirror hit could leave a
speculative full-group read unconsumed in the divide operand collector.
Later writes did not invalidate it. Reusing v31 for sixteen sixes therefore
read its old `[512, 0, ..., 0]` group despite the physical VRF being correct,
raising DZ instead of the reference NX flag.

The collector now cancels reads served by the E0 mirror, suppresses matching
same-cycle hints, and invalidates on matching physical writes with a nonzero
byte mask. This covers pipeline and staged load/iterative writes regardless
of diagnostic settings or VAT ownership. Invalidated outstanding reads drain
their untagged response before replacement. No instruction encoding, NEMU
arithmetic, quantization formula or timing-boundary change is needed.

Local Treadle regression results from the repair cover the production-VRF
reproducer, buffered/returning/pending invalidation, E0 bypass, partial LL
writes, unrelated-EG retention, zero masks, ownerless writes, normal
successor prefetch and baseline VRF behavior. The area-top CHIRRTL structural
check passed. The full all-EG bank traversal was stopped because of Treadle
runtime and is not counted as passed. This server run supplies full-workload
RMSNorm/NVFP4 Difftest acceptance; it does not establish synthesis timing,
area, or broad application-regression acceptance.
